# Плагин QGIS «Сохранение временных слоёв»

Устройство и возможности — в `README.md`.

## Как выпускать версию

1. `tests/run_tests.sh` — все проверки должны пройти.
2. Поднять `version=` и дописать `changelog=` в `temp_layers_to_folder/metadata.txt`.
3. После подтверждения — коммит и пуш, затем релиз с архивом:
   `gh release create vX.Y.Z "$(./build_zip.sh)" --title X.Y.Z --notes "…"`.
4. Дальнейшие шаги (рассылка и обновление у себя) — в локальном `CLAUDE.local.md`,
   если он есть: этот файл не публикуется.

## Грабли

- Папка плагина называется `temp_layers_to_folder`, а не `save_temp_layers`:
  под этим именем в каталоге QGIS есть чужой плагин «Save Temp Layers», и его
  установка затёрла первую версию. Имя папки не менять.
- Полный QGIS (с окном) не запускается с `QT_QPA_PLATFORM=offscreen` —
  падает с кодом 139. Проверки в `tests/` идут без главного окна. Кнопки в
  настоящем QGIS проверяли вторым экземпляром с отдельным профилем:
  `QGIS --profiles-path <временная папка> --code check.py` (окно на пару секунд
  появляется на экране — предупредить пользователя). Чтобы проверить, что
  панель запоминает место, плагин должен грузиться при старте (ссылка в
  `python/plugins` профиля + `[PythonPlugins] temp_layers_to_folder=true`),
  а QGIS — закрываться через `mainWindow().close()`, не `os._exit`.
- `QgsApplication.initQgis()` переключает `QSettings` на
  `~/Library/Application Support/<организация>/…/profiles/default`, и
  `QSettings.setPath` до создания приложения уже не действует. В
  `tests/test_plugin.py` путь задаётся заново сразу после `initQgis()` (с
  `assert`), а созданная папка `temp-layers-tests` удаляется в конце прогона.
  Иначе настройки и тестовая СК копятся между прогонами.
- Пункт меню — в общем подменю «Модули → Альтан-Эко» через
  `altan_toolbar.add_to_menu` / `remove_from_menu`: они же ставят на подменю
  логотип компании (`altan_logo.svg`).
- Кнопка — на общей панели модулей компании «Альтан-Эко» (`altan_toolbar.py`,
  `objectName` `AltanEcoToolbar`). Файл и `altan_logo.svg` одинаковы во всех модулях компании, образцы — в
  `shared/` папки проектов; правятся только там и копируются.
  `objectName` не менять: по нему модули находят общую панель, а QGIS
  восстанавливает её положение.
- Сборка (режим «Собрать проект»): живой проект переключается на data_all и
  сохраняется; копия для архива — `QgsProject().read(файл, DontResolveLayers)`,
  лишние слои убираются, пишется во временный `.<архив>.qgz` **рядом с
  проектом** (иначе относительные пути ./data_all пересчитаются неверно).
- При смене СК проекта карты макетов без своей СК «съезжают» — охват
  пересчитывается (`fit_layout_maps`).
- Шрифты в архив — только со свободной лицензией по полям name 13/14 и
  копирайту (OFL, Apache, GPL…). fsType 2/4 или текст лицензии без открытой —
  платный; ничего не указано — «лицензия неизвестна», тоже не кладём.
- GeoPackage, открытый в QGIS, пишет в журнал `-wal`: последние записи (стиль
  слоя) могут быть только там. Перед zip — `PRAGMA wal_checkpoint(TRUNCATE)`
  и копию проекта `clear()`, иначе в архив попадут `-wal/-shm` или потеряется стиль.
- В тестах `QgsMarkerSymbol([QgsSvgMarkerSymbolLayer(...)])` роняет Python
  (владение объектом) — собирать символ через `changeSymbolLayer(0, …)`.
- Шрифты: Qt называет семейство так же, как запись name ID 16/1 в файле
  («ALSArc», а не «ALS Arc»); сравнение — без регистра, пробелов и дефисов.
- «Сохранять структуру папок» (`copier.py`, ТЗ пользователя от 2026-09-19):
  файлы копируются как есть, раскладка — `copier.target_subdir`. Повторяет пути,
  на которые ссылается проект: у проекта, уже собранного без подпапок, все слои в
  корне data_all — раскладывать нечего (так было у пользователя с 1.5.0; окно
  теперь предупреждает). «Уже в data_all» проверяется по `packager.source_path`,
  а не `saver.layer_path`: у NetCDF (`NETCDF:"файл":var`) и папки-источника
  layer_path пустой. Картинки, лежащие где угодно в data_all, не копируются заново.
- `decodeUri`/`encodeUri` в QGIS 3.40 собирают адрес обратно для ogr, gdal,
  delimitedtext, spatialite, pdal, copc, ept, vpc, mdal (subset, layername,
  /vsizip/, `Ugrid:"…":mesh2d` сохраняются); у gdal для NetCDF/HDF в `path`
  лежит вся строка `NETCDF:"…":var` — файл вынимается regex.
- Формат «native» и флажок структуры независимы (ТЗ пользователя от 2026-09-20):
  формат решает, копировать файлы как есть (`copier.copy_layers` в сборке,
  `saver._copy_native` для временных и слоёв без файла), флажок — подпапки
  (`subdirs`/`structure`). Список слоёв зависит от формата: облака точек и
  сетки появляются только с «native», поэтому `format.currentIndexChanged`
  вызывает `refresh`.
- Qt: у виджетов непоказанного окна `isVisible()` всегда False — в тестах
  `isVisibleTo(окно)`; координаты — после `layout().activate()`.
- macOS: QGIS пишет `.qml` в разложенной форме Юникода (NFD), а Python строки
  в NFC — в тестах имена файлов сравниваются через `unicodedata.normalize`.
- Разделение по типу (ТЗ пользователя, `copier.SPLIT_BY_TYPE`): папка типа
  решается на весь файл (`copier.unit_type`) по типам слоёв, которые его читают,
  плюс для растра — есть ли в контейнере вектор (`container_types`, GDAL
  OpenEx). Уже лежащее в data_all не переносится.
- `setDataSource` перечитывает СК из файла: СК, назначенная вручную (LAS, растр
  без .prj), терялась — `copy_layers` передаёт прежнюю СК в `_repoint`.
- Облако pdal (.las/.laz) QGIS индексирует в фоне в `<имя>.copc.laz` рядом —
  копируется спутником; в тестах индекс ждут через `taskManager()`.
- Сетка с подключёнными наборами данных (`addDatasets`) не переключается на
  копии: `setDataSource` и `readLayerXml` оставляют старые пути в списке
  наборов, удалить их API 3.40 не даёт — такой слой не собирается.
- `subLayers()` провайдера ogr у слоя с `|layername=` возвращает один
  подслой; сколько слоёв в файле — `providerMetadata("ogr").querySublayers(path)`.
- Файл слоя удалили при открытом проекте (macOS): слой остаётся `isValid()` и
  читается через открытый дескриптор, а растры и значки теряются — проект
  собирался «поломанным». Такие слои отсекает `saver.missing_file` в `classify`.
- GDAL не создаёт таблицу GeoPackage, имя которой начинается с `-`, скобки,
  точки и т.п. («The layer name may not contain special characters»): имя
  таблицы — через `saver.gpkg_layer_name`, имя файла остаётся как у слоя.
- Второй экземпляр QGIS: `--profiles-path` — папка, **в которой** лежит
  `profiles/default`, а не сама `profiles` (иначе QGIS создаст пустой профиль
  без плагина, и `pluginMetadata` вернёт `__error__`).
- Проверка сборки на настоящем проекте: скопировать проект и файлы, на которые
  он ссылается, с тем же относительным расположением во временную папку и
  вызвать `packager.consolidate_project` из Python QGIS (нужны и `PROJ_DATA`, и
  `PROJ_LIB`, иначе перепроецирование растров падает на proj.db).
- Memory Layer Saver (чужой модуль, у сотрудников стоит) хранит объекты временных
  слоёв во вложении `layers.mldata` внутри .qgz (старый способ — `<проект>.mldata`
  рядом) и загружает их по `readProject`. Без него слои открываются пустыми, и
  сохранение подменило бы объекты пустым файлом. `saver.mls_unloaded` разбирает файл
  (QDataStream Qt 4.5) и не даёт сохранить пустой временный слой, у которого там есть
  объекты. (Отзыв сотрудницы 2026-09-21 про пустой «Нац парк» оказался другим случаем:
  18.09 `data_all` удалили при открытом проекте, и 1.5.0 при повторной сборке записал
  каждый файл заново пустым — с 1.7.0 такие слои отсекает `saver.missing_file`.) Сохранение проекта
  без модуля вложение не трогает. Если включить модуль при открытом проекте и
  сохранить, его данные тоже не затираются: он переписывает файл, только когда
  временные слои меняли.
- `tests/run_tests.sh` в сборках 3.44+ (`Contents/MacOS/python3.X`): префикс QGIS —
  само приложение (`QGIS_PREFIX_PATH=<.app>`), иначе не грузятся провайдеры
  delimitedtext, pdal, mdal, wms, и тесты падают на CSV, облаках точек и сетках.
- QGIS 3.44: метод, который отдаёт объект по значению, в цепочке с методом, который
  отдаёт ссылку внутрь него, роняет QGIS — временный объект удаляется раньше.
  `legend.style(…).textFormat().font()` уронил QGIS при сборке проекта с легендой в
  макете (1.8.3), `labeling().settings().format().background()` — тесты. В 3.40 те же
  цепочки работают. Промежуточные объекты держать в переменных.
- Проверки не должны трогать профиль пользователя: настройки уводятся во
  временный профиль `tests/_profile` (см. начало `tests/test_plugin.py`).
